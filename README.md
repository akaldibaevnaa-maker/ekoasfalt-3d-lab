# Экоасфальт — Пластик қалдықтарынан жол жасау 3D Виртуалды Зертханасы

Тұрақты даму мақсаттарына (SDG) және қоршаған ортаны қорғауға арналған интерактивті 3D виртуалды зертхана.

## 🌟 Жобаның мазмұны мен мүмкіндіктері:
- **1. Виртуалды 3D Зертхана:** 3 кезеңнен тұратын толық интерактивті тәжірибе:
  - 1-кезең: Шикізатты өлшеу және дайындау (Пластик 100г, Құм 150г, Тас 40г)
  - 2-кезең: 160–180 °C термиялық қыздыру және миксерлеу
  - 3-кезең: Қалыпқа құю және 100 кН гидравликалық пресспен тығыздау
- **2. 360° 3D Модель үлгісі:** Салқындатылған экоасфальт үлгісін жан-жақты бұрып қарау және микроқұрылымын зерттеу.
- **3. Беріктік сынағы (3D):** Жүк көлігі қысымы астында экоасфальт пен дәстүрлі асфальттың төзімділігін салыстыру анимациясы.
- **4. Эко-Калькулятор:** Төселген жол шақырымы бойынша қайта өңделген пластик бөтелкелер саны, үнемделген битум және CO₂ азаюын есептеу.
- **5. Зертханалық жұмыс хаттамасы:** Оқушы мәліметтерін толтырып, PDF форматында басып шығаруға арналған дайын құжат.

## 🚀 Қолданылған технологиялар
- HTML5, CSS3, JavaScript (ES6+)
- Three.js & HTML5 Canvas 3D графикасы
- Web Audio API дыбыс эффектілері
